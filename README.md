# Botanical Letterpress Wedding Invitation

A single-page invitation experience built with React, Vite, and CSS variables.

## Run locally

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Open the local URL shown in the terminal.

## Swap in real content

Edit the placeholder values in [src/App.jsx](src/App.jsx) and [src/utils/content.js](src/utils/content.js) for:
- names
- wedding date and time
- venue details
- gallery photos
- registry links
